# v6 acceptance specification

Outcome: implement and independently prove the seven-checkpoint bench-portfolio contract in
`wishlist-v6-bench-portfolio.md` while keeping production and review ownership conflict-free.

The eight tracked outcomes are: candidate-aware coverage; structured contingent roles; proactive
point-in-time waivers; paired multi-stage outcomes; whole-bench composition; shared versioned shape;
live policy/explanations; and preregistered promotion plus independent land gate.

Deterministic correctness, leakage, nondeterminism, illegal rosters, and mandatory-slice regressions
block. Numerical ambiguity preserves v5. Production changes are not authorized in this review
worktree unless a blocked checkpoint explicitly transfers a correction.

Definition of done is the repository frontend build/typecheck/lint/tests, pipeline pytest, engine
Ruff/full pytest, focused experiment reproduction, artifact parity, secrets/portable-path scan, and
comparison with the immutable base. Local commits to reviewer-owned files are authorized; all remote
and integration actions are not.
